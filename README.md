# Prompt Manager

AI 提示词管理器 — 快速复制、编辑、优化你的提示词，支持坚果云多端同步。

## 功能特性

### 核心功能

- **快速复制** — 单击提示词即可复制到剪贴板，按使用频率自动排序
- **分类管理** — 22 种预设分类 + 自定义分类，支持手动拖拽排序
- **收藏/置顶** — 星标常用提示词，收藏标签页一键访问，收藏项排最前
- **标签系统** — 为提示词添加标签，输入 `#标签名` 快速筛选
- **增强变量** — 支持文本、下拉选项、数字默认值等变量格式，复制或插入前填写
- **实时搜索** — 搜索标题、内容和标签
- **批量操作** — 全选、批量删除提示词
- **评分与排序** — 为提示词设置 1-5 星评分，支持按评分、使用次数等排序
- **版本历史** — 编辑提示词时自动保存旧版本，支持恢复历史内容
- **使用分析** — 统计提示词使用次数、热门提示词和常用网站

### AI 润色

- 调用 AI API 一键诊断和优化提示词
- 支持 5 种优化模式：快速润色、专业结构化、变量模板化、严格输出格式、诊断问题
- 结构化展示诊断、优化结果、变量建议、输出格式和风险提示
- 支持复制结果、替换当前提示词、另存为新提示词
- 支持 4 种附加优化方向：角色设定、输出要求、示例参考、约束条件
- 兼容 OpenAI、Claude、通义千问等 OpenAI 格式 API

### 右键菜单

- 选中网页文字 → 右键 →「保存为提示词」→ 自动打开新建弹窗并预填内容
- 在网页输入框中右键 →「插入提示词」→ 从收藏、常用、最近创建中选择并插入
- 插入带变量的提示词时，会先填写变量再插入
- 快捷键 `Ctrl+Shift+S` 同样可以保存选中文字

### 坚果云同步

- 通过 WebDAV 协议自动同步提示词、分类、API 配置等数据
- 启动时自动拉取远程数据，编辑后 15 秒自动推送
- 支持定时拉取（默认 2 小时，可配置 5-1440 分钟）
- 内容哈希检测，无变化时跳过上传，节省流量
- 强制 HTTPS，远程数据结构校验

### 其他

- 多语言支持（中文 / English）
- JSON 文件导入导出备份
- GitHub API 自动检测新版本
- 侧边栏宽度可拖拽调节

## 安装方法

### 首次安装

1. 访问 [Releases](https://github.com/hg199074jin/Prompt_Manager/releases) 页面
2. 下载最新版本的 `.zip` 文件并解压
3. 打开 Chrome 浏览器，访问 `chrome://extensions`
4. 开启右上角的"开发者模式"
5. 点击"加载已解压的扩展程序"
6. 选择解压后的文件夹

### 更新

1. 插件会自动检测新版本（Popup 顶部显示更新提示）
2. 下载新版本并解压覆盖
3. 在 `chrome://extensions` 页面点击"重新加载"

## 使用方法

### 快速复制

1. 点击浏览器工具栏的插件图标
2. 浏览分类或搜索提示词
3. 单击提示词即可复制到剪贴板（使用频率自动提升排序）

### AI 润色

1. 在 Options 页面找到需要优化的提示词
2. 点击提示词卡片上的「AI 润色」
3. 选择优化模式，并按需勾选角色设定、输出要求、示例参考、约束条件
4. 点击「开始润色」等待 AI 返回结构化结果
5. 根据结果选择「复制结果」「使用优化结果」或「另存为新提示词」

AI 返回结果会分区显示：

- **诊断**：指出原提示词的问题
- **优化结果**：可直接使用的新版提示词
- **变量建议**：建议抽成 `{{变量}}` 的字段，可单独复制变量名
- **输出格式**：建议的回答结构
- **风险提示**：潜在歧义、约束缺失或使用提醒

#### 优化模式

优化模式决定这次 AI 润色的主目标，一次选择一个即可。

| 模式 | 适合场景 | 生成效果 |
| --- | --- | --- |
| 快速润色 | 原提示词基本可用，只想让表达更清楚 | 保留原意，轻量改写，补充少量必要说明 |
| 专业结构化 | 重要提示词、长期复用提示词、复杂任务 | 整理为角色、任务、背景、步骤、输出要求、约束条件等结构 |
| 变量模板化 | 想把提示词做成可重复填写的模板 | 自动识别可变内容，生成 `{{主题}}`、`{{受众}}`、`{{语气}}` 等变量 |
| 严格输出格式 | 需要 AI 每次按固定结构回答 | 强化 Markdown、表格、JSON、分段结构或字段清单等输出要求 |
| 诊断问题 | 不确定提示词为什么效果不好 | 先指出目标不清、背景不足、格式缺失、约束不足等问题，再给优化建议 |

#### 优化方向

优化方向是附加增强项，可以多选。它们会影响生成结果。

- **添加角色设定**：让提示词加入“你是一位……”这类身份设定，适合写作、营销、编程、审计、教学等专业任务。
- **细化输出要求**：补充字数、结构、语气、格式、交付标准等要求，是最常用的增强项。
- **添加示例参考**：加入示例或示例占位，让 AI 更容易理解你想要的风格和输出形态。
- **增加约束条件**：加入“不要做什么”“必须包含什么”“语气边界”等限制，减少跑偏。

#### 推荐组合

| 目标 | 推荐选择 |
| --- | --- |
| 日常轻量优化 | 快速润色 + 细化输出要求 |
| 做高质量长期提示词 | 专业结构化 + 添加角色设定 + 细化输出要求 + 增加约束条件 |
| 做可复用模板 | 变量模板化 + 添加角色设定 + 细化输出要求 |
| 做固定格式输出 | 严格输出格式 + 细化输出要求 + 增加约束条件 |
| 排查提示词不好用 | 诊断问题 + 细化输出要求 |

示例：

```text
模式：变量模板化
方向：添加角色设定、细化输出要求

可能生成：
你是一位{{角色}}，请围绕{{主题}}，为{{目标受众}}写一篇{{平台}}文案。

要求：
1. 语气：{{语气}}
2. 字数：{{字数}}
3. 输出格式：{{输出格式}}
```

另一个示例：

```text
模式：严格输出格式
方向：细化输出要求、增加约束条件

可能生成：
请严格按以下格式输出：

## 一、核心结论
## 二、详细分析
## 三、行动清单

约束：
- 不要输出格式之外的解释
- 每个建议必须可执行
```

### 增强变量

在提示词内容中使用 `{{...}}` 标记需要每次填写的部分：

```
你是一位{{角色}}，请帮我写一篇关于{{主题}}的文章，目标读者是{{受众}}，字数约{{字数}}字。
```

点击这条提示词时，弹出填写弹窗，填完后自动替换再复制到剪贴板。

支持的变量格式：

```
{{变量名}}
{{变量名:填写提示}}
{{变量名|选项1,选项2,选项3}}
{{变量名:number:默认数字}}
```

示例：

```
请帮我写一篇关于 {{topic:请输入主题}} 的文章，语气使用 {{tone|专业,口语,犀利}}，字数约 {{word_count:number:800}} 字。
```

- `{{topic:请输入主题}}`：显示文本输入框
- `{{tone|专业,口语,犀利}}`：显示下拉选项
- `{{word_count:number:800}}`：显示数字输入框，默认值为 800
- 同名变量自动统一替换
- 留空则保持原始变量占位符
- 不含 `{{...}}` 的提示词直接复制，无弹窗

### 收藏与标签

- **收藏**：点击提示词右侧的星标按钮，收藏后可在「⭐ 收藏」标签页快速找到
- **标签**：新建或编辑提示词时可添加标签（输入后按 Enter），支持自动补全历史标签
- **标签搜索**：在搜索框输入 `#标签名` 只显示带该标签的提示词

### 右键菜单

保存网页文字：

1. 在任意网页选中文字
2. 右键 →「保存为提示词」
3. 自动打开 Options 页面的新建弹窗，选中文字已预填

插入提示词：

1. 在网页输入框中右键
2. 选择「插入提示词」
3. 从「收藏提示词」「常用提示词」「最近创建」中选择提示词
4. 提示词会插入到当前输入框光标位置
5. 如果提示词包含变量，会先弹出变量填写窗口

> 当前版本使用右键插入作为跨网站输入方式，不启用页内悬浮面板，避免不同 AI 网站编辑器适配带来的不稳定。

### 评分、使用分析与版本历史

在 Options 页面中可以使用这些管理能力：

- **评分**：新建或编辑提示词时设置 1-5 星评分
- **排序**：支持按更新时间、创建时间、使用次数、评分、名称排序
- **使用分析**：点击顶部「使用分析」查看总使用次数、热门提示词和常用网站
- **版本历史**：每次编辑提示词前会自动保存旧版本，点击提示词卡片上的「历史」可查看并恢复

### 管理提示词

1. 点击插件图标，点击设置按钮进入 Options 页面
2. 在 Options 页面可以：
   - 新建、编辑、删除提示词
   - 管理分类（添加、编辑、删除、排序）
   - 使用 AI 润色功能优化提示词
   - 查看使用分析
   - 查看并恢复历史版本
   - 设置评分并按评分/使用次数排序
   - 配置 API 和坚果云同步

### 坚果云同步配置

1. 在坚果云客户端（Win/Mac）新建一个同步文件夹（如 `Prompt_Extension`）
2. 在坚果云网页端「安全选项」中生成应用密码
3. 在 Options 页面点击「同步设置」按钮
4. 填写配置：
   - 服务器地址：`https://dav.jianguoyun.com/dav`（不含用户名）
   - 用户名：你的坚果云邮箱
   - 应用密码：步骤 2 生成的密码
   - 远程文件路径：`/Prompt_Extension/prompt-manager-sync.json`
5. 点击「测试连接」验证后保存
6. 点击「立即同步」首次上传数据

> 坚果云免费账户每月 1GB 上传流量，提示词文件极小，完全够用。

### 配置 AI API

1. 在 Options 页面点击「API 配置」按钮
2. 填写 API 地址、Key、模型名称
3. 点击「测试连接」验证配置
4. 保存后即可使用 AI 润色功能

支持的 API：
- OpenAI（GPT-4、GPT-3.5）
- Claude
- 通义千问
- 其他 OpenAI 兼容格式 API

## 技术栈

- HTML + CSS + JavaScript（原生，无框架）
- Chrome Manifest V3
- chrome.storage.local 数据存储
- WebDAV 协议（坚果云同步）
- chrome.i18n 国际化

## 项目结构

```
prompt-manager/
  manifest.json        # 扩展配置（权限、快捷键、CSP）
  background.js        # Service Worker（AI 润色 + WebDAV 同步 + 右键菜单）
  popup.html/css/js    # 弹窗界面（快速复制、收藏、标签、模板变量）
  options.html/css/js  # 设置页面（分类管理、提示词 CRUD、API/同步配置）
  storage.js           # 数据存储层
  context-menu-utils.js # 右键菜单提示词分组和变量工具
  ai-polish-utils.js   # AI 润色请求构建、结果解析和缓存 key 工具
  pro-utils.js         # 增强变量、使用分析等本地 Pro 工具
  icons/               # 扩展图标
  _locales/            # 国际化文件
```

> `docs/` 和 `test/` 为本地资料与测试文件，不参与扩展运行，也不会上传到仓库。
